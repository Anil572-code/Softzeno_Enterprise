# Softzeno Tech Home Hero Composition v2.5.0

This release refines only the first-screen Home composition.

## Goals

- Use substantially more of the desktop viewport width without making the page feel cramped.
- Give the product preview visual weight comparable to the headline.
- Preserve a complete first-screen landing experience before the audience strip begins.
- Keep the existing clean Softzeno Tech visual system, typography, colors, motion, and responsive behavior.
- Avoid adding decorative noise, new gradients, glass effects, or extra floating elements.

## Desktop composition

- Home-specific maximum width increases to approximately 1408–1440px on large displays.
- The grid moves to roughly a 46/54 text-to-product balance.
- Product preview grows to approximately 656–688px while retaining the existing product UI.
- Headline remains controlled and readable instead of becoming an oversized billboard.
- Short desktop viewports use a compact fallback so content cannot clip.

## Responsive behavior

Tablet and mobile layouts remain governed by the existing v2.4.0 responsive system. This patch intentionally changes only desktop hero density.
