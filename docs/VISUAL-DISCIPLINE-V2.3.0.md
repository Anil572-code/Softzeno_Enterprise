# Softzeno Tech Visual Discipline v2.3.0

This release tightens the Softzeno Tech visual system around enterprise readability, neutral surfaces, controlled purple accents and a clean first viewport.

## Key changes

- The Home hero owns the first desktop viewport; following sections no longer visually compete with the landing experience.
- Purple is reserved for brand emphasis, actions, active states and data instead of washing every surface.
- Light mode uses high-contrast neutral text and white/near-white surfaces.
- Dark mode uses near-black neutral surfaces with vivid but controlled violet accents.
- Gradient text is removed in favour of a solid brand accent for more consistent readability.
- Product and page diagrams use neutral surfaces and solid brand states rather than decorative glow.
- Buttons are solid, high-contrast and shadow-free.
- Decorative hero grids and radial haze are removed.
- Home product preview is simplified by removing nonessential preview/footer labels.

The design goal is compact, premium enterprise software rather than decorative SaaS styling.
