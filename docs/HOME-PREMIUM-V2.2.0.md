# Softzeno Tech Home Premium v2.2.0

This release refines only the main landing page and its home-specific styling. It keeps the v2.1.0 global enterprise system intact.

## Direction

- Compact enterprise hierarchy rather than decorative SaaS styling.
- Neutral light and dark surfaces with purple used as a controlled brand accent.
- Smaller, more deliberate hero typography.
- Product-led visual language with no floating decorative cards or large gradients.
- Clear separation between capabilities, role perspectives, operational value, workflow, enterprise readiness and industries.
- Illustrative product data is explicitly labelled as such.
- No invented customer logos, certifications or performance claims.
- Minimal motion: one short role-preview transition plus existing reveal behavior.

## Home structure

1. Focused hero with product preview.
2. Compact operational audience strip.
3. Six core platform capabilities.
4. Learner / coordinator / manager workspace preview.
5. Three operational value pillars.
6. Four-stage workflow.
7. Enterprise-ready platform foundation.
8. Industry use cases.
9. Restrained final demonstration CTA.

## Responsive behavior

The layout is designed for 320px, 360px, 375px, 390px, 768px, 1024px, 1280px and 1536px viewport classes. The product preview remains visible on mobile, but non-essential chart detail is removed at narrow widths.

## Runtime

Use `npm start`. Vite remains bound to `127.0.0.1:6066` with `--strictPort`.
