# Softzeno Tech Brand Migration

## Corporate brand

- Company: **Softzeno Tech**
- Product: **Softzeno Interactive Safety Platform**
- Brand line: **Technology for Safer Workplaces.**
- Primary visual direction: deep violet, electric purple and restrained magenta accents.

## Logo

The supplied `src/assets/brand/softzeno.png` remains the source artwork. Optimized transparent web exports are generated under `public/brand/` for navigation, favicon/PWA and structured metadata use.

## Theme direction

Purple is the primary interaction and identity colour in both light and dark themes. Blue is no longer the dominant interface colour. The multicolour logo remains intact and is used as a brand mark rather than as a source for rainbow UI styling.

## Product positioning

Softzeno Tech is the company brand. The website currently promotes the Softzeno Interactive Safety Platform as its featured enterprise product.
