# Softzeno Tech Professional Refinement v2.1.0

This release standardises the marketing website around a compact enterprise visual language.

## Direction

- Inter Variable remains the single UI and marketing typeface.
- Purple is the brand accent, not the surface colour.
- Light mode uses neutral white/slate surfaces.
- Dark mode uses charcoal/near-black surfaces with purple only for interaction and emphasis.
- Large gradients, glassmorphism, glow-heavy panels, rotating artwork and permanent floating motion are removed.
- Hero typography, cards, forms, header, footer and section spacing are reduced to a tighter enterprise scale.
- Motion is limited to short opacity/translate transitions and functional data animation.

## Interaction

Route view transitions are disabled to prevent browser-level animation from competing with Framer Motion. Buttons retain a small arrow movement and cards use a 2px hover lift only.

## Responsive intent

The system is mobile-first below 48rem, with compact headings, stacked CTAs, simpler hero artwork and touch-safe controls.
