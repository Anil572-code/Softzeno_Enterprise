# Softzeno Tech UI/UX Closure v2.4.0

This release closes the remaining visual-system issues without changing the established information architecture.

## Scope

- Ensures the Home hero owns the first desktop viewport below the 64px header.
- Keeps the operational-audience strip fully below the initial landing fold.
- Standardises readable neutral typography in light and dark themes.
- Reserves Softzeno purple for brand emphasis, actions, selection and meaningful data.
- Tightens shared page heroes and section rhythm.
- Neutralises the footer so it finishes the page rather than competing with it.
- Improves mobile navigation with Escape handling, focus entry/return, body scroll locking, backdrop dismissal and automatic desktop recovery.
- Removes the last browser View Transition opt-in from the brand link.
- Preserves `npm start` on strict port 6066.

## Design principle

The interface should remain premium when all animation is disabled. Motion supports hierarchy; it does not create hierarchy.
